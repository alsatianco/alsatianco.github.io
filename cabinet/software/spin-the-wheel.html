Spin the Wheel

A wheel spinner and random picker that keeps your wheels in your browser. It works offline, and it picks winners with real cryptographic randomness.

What it does

  • Weighted entries, elimination mode, seed mode, tournament mode, manual stop, and a mystery wheel.
  • Save named wheels and open them again later.
  • Share a wheel as a link, either fully editable or spin-only.
  • Paste many entries at once, import CSV, and export the wheel, the results as CSV, or an audit file as JSON.
  • Templates, themes, event presets, sounds, celebration effects, and full screen.

Fairness

Winners are picked with your browser's cryptographic random number generator, crypto.getRandomValues(). Read how fairness works.

Privacy

Your entries, settings, and results stay in your browser. They leave it only when you share or export a wheel. A shared link carries the wheel data inside the link itself, so anyone with the link can open that wheel.

This is not a no-analytics site: it uses Cloudflare Web Analytics for total visits and page speed, not for ads or profiles. Read the privacy page.

Source code

Spin the Wheel is plain HTML, CSS, and JavaScript, with no backend and no build step. The source code is on GitHub under the MIT License.
