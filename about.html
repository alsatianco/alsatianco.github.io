About

Alsatian Studio is a one-person studio. I have made games and apps since around 2011, and today I mostly make software.

Some projects are family projects. Meadow Math was built mostly by my son, with ideas and content from my wife. VoVo Science was made by my wife for our daughter.

How it started

My first games were small Java games for Nokia phones, sold in Nokia's Ovi Store around 2011. Then I made games for Windows Phone and Windows 8, and later for Android and desktop computers, with Java, Game Maker, and other tools.

The Nokia store and the Windows Phone store have closed, and most of those early games closed with them. A few are still online. Zombies: Deads Fall, from 2014, is still in the Microsoft Store, and some early game jam games are on GameJolt.

This website lists the projects that you can still get from GitHub, Google Play, itch.io, the Chrome Web Store, and YouTube. The oldest one is Nia in Mushroom World, from December 2015, so the updates start there.

The name

The studio is named after the Alsatian, the dog also known as the German Shepherd. It is a working dog: loyal, calm, and careful. That is how I want the software to feel. The games are allowed to be a little less calm.

What each project page tells you

  • Price. Free, pay what you want, or the exact price, before you click.
  • Source code. Whether the code is open, and under which license.
  • Your data. What the project keeps, where it keeps it, and whether it uses analytics.
  • Status. What does not work yet, or that a project is no longer updated.

Today, every project is free to use, and none of them needs an account. The newer software is open source, under the MIT or Apache 2.0 License. The older games and Android apps are not open source.

Three websites, Spin the Wheel, Meadow Math, and VoVo Science, use Cloudflare Web Analytics to count visits in an anonymous, aggregated form. Each project page says whether it uses analytics.

This website

This website has no analytics and sets no cookies. Fonts and images are served from this site, so your browser does not contact any other company when you read it. Links to GitHub, Google Play, itch.io, and YouTube open those sites.

The text uses the Recursive typeface, under the SIL Open Font License.

Contact

For software, the best way to reach me is an issue on the project's GitHub page. All open-source projects are on GitHub. Games have comment pages on itch.io. You can also find me on LinkedIn.
