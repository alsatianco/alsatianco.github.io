What Kawasan is

Swap an apache/kafka container for Kawasan, and existing Kafka clients and tools keep working without changes. Kawasan uses Raft for metadata, so there is no ZooKeeper, and RocksDB for durable storage.

The single-node broker is well tested and suitable for development, testing, and production on a single server.

Run Kawasan

Build and start a local broker. The script checks your tools, builds, and starts the broker on port 9092:

git clone https://github.com/alsatianco/kawasan.git
cd kawasan
./scripts/quick-start.sh

Or run it with Docker Compose from the repository:

docker compose up -d

Then point any Kafka client at localhost:9092. Prometheus metrics are at :9094/metrics, and /health, /readiness, and /liveness are HTTP probes. Building needs GCC 11 or newer (or Clang 13 or newer) and CMake 3.20 or newer.

Known limits

  • TLS between clients and the broker is not implemented. The broker refuses an SSL configuration instead of serving plain text, so end TLS at a proxy.
  • Raft traffic between brokers is plain text. raft.ssl.* settings are accepted but not enforced.
